# تشغيل وبناء برنامج إدارة علائق وتغذية الماشية على سطح المكتب (Electron)

تم تجهيز هذا المشروع بالكامل ليعمل كتطبيق سطح مكتب مستقل (Desktop App) لأنظمة **Windows** و **Mac** و **Linux** بدون الحاجة للإنترنت وبحفظ محلي آمن للبيانات.

---

## 🚀 خطوات التشغيل والبناء على جهازك:

### 1. المتطلبات الأولية:
- تثبيت **Node.js** (الإصدار 18 أو أحدث) من الموقع الرسمي: [https://nodejs.org](https://nodejs.org)

---

### 2. تحميل ملفات المشروع:
- من شريط أدوات AI Studio في الأعلى، اضغط على زر القائمة ثم اختر **Export as ZIP** أو **Export to GitHub**.
- قم بفك ضغط الملف على جهاز الكمبيوتر.

---

### 3. تثبيت الحزم (Dependencies):
افتح موجه الأوامر (Terminal أو Command Prompt / PowerShell) داخل مجلد المشروع، ثم نفذ:
```bash
npm install
```

---

### 4. تجربة وتشغيل البرنامج على سطح المكتب (Development):
لتشغيل البرنامج في نافذة سطح المكتب وتجربته مباشرة:
```bash
npm run electron:dev
```

---

### 5. بناء ملف التثبيت التنفيذي لسطح المكتب (.exe للويندوز):
لإنشاء ملف التثبيت المكتبي الجاهز للتوزيع:
```bash
npm run electron:build
```
- بعد انتهاء البناء، ستجد ملف التثبيت التنفيذي `.exe` (وملف النسخة المحمولة Portable) داخل مجلد:
  `release/`

---

## ⚙️ مميزات نسخة سطح المكتب:
- ✅ **حفظ محلي تلقائي (Offline Data):** جميع بيانات العلائق، الخامات، الموازين، العنابر، والمخزن تُحفظ على جهازك تلقائياً عبر التخزين المحلي.
- ✅ **طباعة مباشرة:** دعم كامل لطباعة كشوف السائقين وأوامر المكسر (Ctrl + P).
- ✅ **نافذة مخصصة وواجهة سريعة:** بدون شريط متصفح وبأداء فائق مع دعم كامل للغة العربية.
